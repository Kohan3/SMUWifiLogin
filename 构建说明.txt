================================================================
  南方医科大学校园网 Portal 一键连接 App —— 构建与安装说明
  包名：com.smu.wifilogin
================================================================

本文件夹是【完整可编译的 Android 源码工程】，不是 APK 安装包。
APK 必须由源码编译生成（Android 官方限制，任何电脑都要走这一步）。
下面给出 3 种拿到可安装 APK 的方法，任选其一。

----------------------------------------------------------------
方法一（最推荐，最简单）：Windows + Android Studio 出包，照点即可
----------------------------------------------------------------
【第 1 步：安装 Android Studio】
1. 打开官网 https://developer.android.com/studio ，下载 Windows 版（约 1GB）。
2. 双击 android-studio-*.exe → 一路 Next → 到 "Choose Components"
   确认勾选了 Android Studio 和 Android SDK → Next → 安装 → Finish。
3. 首次启动弹 "Import Android Studio Settings" → 选 "Do not import settings" → OK。
4. Setup Wizard：Next → 选 "Standard"（标准，会自动装好 SDK）→ Next →
   选主题（随便）→ Next → 点 "Verify settings" / "Finish" →
   等待它联网下载 SDK 和组件（几分钟，必须联网）→ Finish。

【第 2 步：打开本工程】
5. 欢迎界面点 "Open" → 选择解压出来的 SMUWifiLogin 文件夹
   （就是里面含 build.gradle / app 子文件夹的那一层）→ OK。
6. 打开后会自动 "Gradle Sync"（底部状态栏有进度）。若弹窗问是否信任 /
   下载 Gradle 8.2 → 全部点 "Trust / Sync / Retry"，让它联网下载依赖
   （OkHttp、Jsoup 等都从网上下，必须联网，约 1~3 分钟）。
7. 等底部显示 "Gradle sync finished" 且无红色报错，说明工程就绪。

【第 3 步：出 APK】
8. 顶部菜单栏点 Build → Build APK(s)（注意不是 Build Bundle）。
9. 等编译完成（首次更久，1~3 分钟）。右下角弹 "APK(s) generated
   successfully" → 点 **locate** → 自动打开文件夹：
   SMUWifiLogin\app\build\outputs\apk\debug\app-debug.apk
10. 这个 app-debug.apk 自带调试签名，可直接装到手机，无需自己签名。

【第 4 步：装到小米 14 Pro】见下方“装到手机（小米专属）”段。

【常见问题】
- 卡在 "Downloading Gradle / dependencies"：多为网络问题，确认能访问
  dl.google.com 和 maven 仓库；可重试或挂代理后点 File → Sync Project。
- 报 "Android SDK not found"：安装时没勾 SDK，重跑安装程序补装。
- 报 Kotlin/AGP 版本不兼容：说明 Studio 太旧，升级到 Hedgehog(2023.1)
  及以上（Koala / Ladybug 更好），它支持本工程的 AGP 8.2.2。
- 想更省事：手机开 USB 调试连电脑，顶部点绿色 ▶ Run，Studio 会自动
  编译并直接装到手机并启动（但小米对 USB 安装有额外限制，见小米段）。

----------------------------------------------------------------
方法二：正式签名包（要发给别人 / 上架才需要）
----------------------------------------------------------------
Build → Generate Signed Bundle / APK → 选 APK →
Create new 新建 keystore（填密码和别名，记住！）→ 选 release →
得到 app-release.apk（手机开“未知来源”即可安装）。

----------------------------------------------------------------
方法三（不用本地装 SDK）：GitHub 云端自动编译出 APK（已配置好）
----------------------------------------------------------------
本工程已内置 GitHub Actions 配置：.github/workflows/build-apk.yml
推到 GitHub 后会自动在云端编译并产出 APK，全程不需要你本地装 SDK。

【操作步骤】
1. 登录 github.com → 右上角 “+” → New repository → 起个名（如
   SMUWifiLogin）→ 选 Public 或 Private 均可 → Create repository。
2. 把本 SMUWifiLogin 文件夹里的【全部内容】上传到仓库：
   - 最简单：仓库页 “Add file” → Upload files → 直接把 SMUWifiLogin
     文件夹整体拖进去（会保留 .github 等子目录结构），写个 commit 说明
     → Commit changes。
   - 或用 Git：在本地仓库目录执行
       git init && git add -A && git commit -m "init"
       git branch -M main
       git remote add origin <你的仓库地址>
       git push -u origin main
3. 上传后 GitHub 自动开始编译：点顶部 “Actions” 标签可见进度；
   也可在 Actions → Build Debug APK → 右侧 “Run workflow” 手动触发。
4. 编译完成（约 3~6 分钟）→ 进入该次运行 → 底部 “Artifacts” →
   下载 app-debug-apk（里面就是 app-debug.apk）。
5. 把 app-debug.apk 传到小米 14 Pro 安装（见“装到手机”段）。

【提示】
- 首次编译会联网下载依赖与 SDK 组件，属正常现象。
- 若要出正式签名包，可在工作流里加 signing 步骤，或本地另走方法二。
- 改代码后再次 push，会重新编译出新 APK。

----------------------------------------------------------------
装到手机（重点：小米 14 Pro / HyperOS 专属）
----------------------------------------------------------------
【推荐：传 APK 到手机，用「文件管理」安装，最省事】
1. 把 app-debug.apk / app-release.apk 传到手机
   （数据线复制，或微信“文件传输助手”发送）。
2. 微信发的 APK 后缀常被改成 .apk.1，用「文件管理」长按重命名回 .apk。
3. 授权“未知来源”：
   设置 → 隐私保护 → 特殊权限设置 → 安装未知应用 →
   找到「文件管理」→ 开启“允许安装未知应用”。
   （HyperOS 也可能在：设置 → 应用设置 → 授权管理 → 应用权限管理）
4. 用「文件管理」找到 APK 点击安装。
5. 小米会先弹“安全守护 / 风险应用”扫描提示：
   点「继续安装」或「仍要安装」，不要被它劝退。
   （这是小米对未上架商店应用的常规提示，不是真有病毒。）

【不推荐用 Android Studio 直接 Run 装：】
小米对“USB 安装”有限制——开发者选项里要开「USB 安装」，
且通常需要登录小米账号；部分机型对“USB 调试（安全设置）”还有
约 72 小时等待期。所以优先用上面的“传文件+文件管理安装”方式。

【装好后联网：】
连上 SMU-C / SMU-C-2.4 WiFi（先关 VPN/代理）→ 打开 App →
填账号密码 → 点「一键连接」。

----------------------------------------------------------------
使用
----------------------------------------------------------------
连上 SMU-C / SMU-C-2.4 WiFi（先关 VPN/代理）→ 打开 App →
填账号密码 → 点「一键连接」。失败可在「高级设置」里按 F12 抓包
校准选择器，或切到“WebView 注入”方案。

技术栈：Kotlin + OkHttp 4.12.0 + Jsoup 1.17.2，minSdk 24 / targetSdk 34。
